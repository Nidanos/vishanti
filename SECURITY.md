# Security

Please **don't open a public issue** for a security problem. Email **hello@nidanos.com** with "Security" in the subject, what you found, and how to reproduce it. We reply within 3 working days, and tell you when it's fixed.

Of most interest:
- reading or changing another learner's data;
- getting an exercise's hidden tests or reference solution;
- reading a learner's stored AI key;
- running code outside the sandbox.

Please test only against your own copy (see the [README](README.md#run-it-yourself)), never against other people's accounts on the hosted site.
